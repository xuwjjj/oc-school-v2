## 7) توصيات متبقية (أولوية عالية)

1. **كوكيز `HttpOnly` + CSRF** بدل `localStorage`.
2. **تحديد الحقول المرجعة** حسب الدور (بيانات الطالب الحساسة للمشرف فقط).
3. **سجل تدقيق (Audit Log)** لكل عملية حساسة: من عدّل/حذف ومتى.
4. **نسخ احتياطي دوري** لقاعدة البيانات (ملف SQLite) مع اختبار الاستعادة.
5. **2FA** لحساب المشرف.
6. **HSTS + CSP** على مستوى الاستضافة.
